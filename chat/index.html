Neue Verbindung

Der Link gilt nur für eine Verbindung. Lass diese Seite offen, bis ihr verbunden seid.

Sobald die andere Person den Code eingefügt hat, seid ihr verbunden.

Vergleicht diesen Code persönlich oder per Telefon. Ist er auf beiden Seiten gleich, spricht niemand dazwischen.

Neuer Gruppenraum

Du bist zuerst allein im Raum. Danach lädst du Leute per Link ein. Wer neu dazukommt, braucht nur eine Verbindung zu irgendeinem Mitglied, die anderen Verbindungen entstehen von selbst. Bis zu 8 Personen.

Nachrichten gehen direkt an jedes Mitglied, nichts läuft über einen Server. Neue Mitglieder sehen die letzten 30 Textnachrichten und alles ab ihrem Beitritt. Es gibt keinen Raumverwalter: Jeder kann einladen, niemand kann jemanden ausschließen.
